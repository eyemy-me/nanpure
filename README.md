# nanpure　～個性的なナンプレ～

対外的には「個性的なナンプレ」。  
開発室では「変なナンプレ」。

自動チェックモードで、残り1文字のマス目を確定連鎖オープン。
軽快に遊べます。
また、長考、迷い、メモ、間違い、ヒント、連鎖など、
プレイヤーの「妙な解きっぷり」を観測するブラウザゲームです。
